# Ручная проверка на устройстве

Чек-лист того, что не покрывает Jest: нативные сканер, пикеры, уведомления и календарь (задача 4.7 [плана](./IMPLEMENTATION_PLAN.md)). Он растёт вместе с задачами. Сейчас в нём захват документа (этап 2), анализ с экраном документа (задачи 4.1 и 4.2), главный экран (4.5) и действия с документом (4.4). С задачи 4.1 «Разобрать документ» сразу запускает анализ, поэтому устройству нужен `EXPO_PUBLIC_API_URL` с адресом dev-сервера, доступным с телефона (на нём `MockLlmProvider`). Без него анализ закончится ошибкой связи с «Повторить». Уведомление → документ, «В календарь» и восстановление без файлов страниц добавятся с задачами этапов 4 и 5.

## Подготовка

1. Development build на телефоне или на эмуляторе с Google Play (скилл `run-app`, для Android `npx expo run:android`). Сканер ML Kit работает только с Google Play services.
2. Тестовый набор (подробности в [scripts/eval/README.md](../scripts/eval/README.md)):

   ```bash
   python3 -m venv scripts/eval/.venv
   scripts/eval/.venv/bin/pip install -r scripts/eval/synthetic/requirements.txt
   scripts/eval/.venv/bin/python scripts/eval/synthetic/tenancy_kit.py
   scripts/eval/synthetic/push-android.sh
   ```

   Скрипт кладёт файлы на все подключённые Android-устройства: в «Загрузки → DocNavigatorTest» для «Файл» и в альбом DocNavigatorTest для «Фото из галереи». На iOS набор переносится вручную: содержимое `scripts/eval/out/tenancy/Download/DocNavigatorTest` — в «Файлы», фото из `Pictures/DocNavigatorTest` — в «Фото». Сроки в наборе считаются от дня генерации, поэтому перед проверкой анализа набор лучше пересоздать.

3. Для сканера: распечатка `01-tenancy-agreement-full.pdf` или этот PDF, открытый на мониторе.
4. Для главного экрана (шаги 30–35) — 120 синтетических документов в базе приложения на Android (Node 22.6+, отладочная сборка):

   ```bash
   node --experimental-strip-types scripts/smoke/seed-android-documents.mjs
   ```

   Скрипт останавливает приложение, сохраняет его базу в `scripts/smoke/out/` и печатает команду, которая вернёт её обратно. Анализы берутся из фикстур, сроки — от сегодняшнего дня: четыре в «Требует внимания», остальные далеко. Файлов страниц у засеянных документов нет («Оригинал недоступен»). Названия кончаются на «· тест NNN».

5. Dev-сервер для анализа: `LLM_MOCK_DELAY_MS=4000 npx expo start --dev-client --port 8082` (порт из `EXPO_PUBLIC_API_URL` в `.env.local`; для эмулятора хост — `10.0.2.2`). С задержкой видно «Читаем документ…», а в терминале — события `analyze.start` и `analyze.end`. Адрес сервера анализа показан в «Настройках».

На Android 17 фото из набора находятся в пикере через Collections → From this device → DocNavigatorTest (у всех файлов одна дата, порядок в альбоме не по имени). В «Файл» открывайте корень «Загрузки» (Downloads): в корне «Документы» видны только PDF.

В development build Expo сам не даёт экрану погаснуть, поэтому `keepScreenAwake()` на время анализа (ANL-3) проверяется только в preview-сборке.
